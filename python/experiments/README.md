# Experiments

Each runs from the repository's root as `uv run python -m experiments.<folder>.<name>` (the tools at
the top as `experiments.<name>`). With no options it reproduces the numbers `IDEAS.md` quotes, on the
Prosperity data in `references/`. Four groups:
- **`day/`**: the Arena's round tools (`round_start`, `run_review`, `fill_depletion`, `fill_queue`, `fill_state`, `spread_episodes`, `ladder_search`, `queue_place`, `touch_imbalance`, `tape_gen`, `tape_eval`, `tape_regimes`, `tape_character`, `gen_identify`, `burst_hits`, `pretrain_forecast`, `pretrain_dump_bot`, `r3_edges`, `pnl_corr`, `gen_calibrate`, `family_rust`, `tape_from_logs`, `tape_book`, `latent_filter`, `r3_edges`, `pnl_corr`, `loss_anatomy`, `forecast_quality`, `leaderboard_curves`, `standings`), and
  `imbalance`, `informed`, `predict` and `p3_smile`, kept here because the bots' comments name them (the first table).
  Those on our engine take `--data DIR --days ...`, `--format` its plug-in, `--bot` (`arena.cli.add_dataset_arguments`).
- **`study/`**: two one-offs (`sim_regimes`, `one_class`; the second table).
- **`prosperity/`**: the Prosperity-era experiments, moved from `day/` and `study/` on 7 Nov (the third and fourth
  tables): our engine on Prosperity-format data, their numbers in `IDEAS.md` priors. `python/tests/test_experiments.py`
  runs about half of them on drill-format data.
- **The tools at the top** (the last table): data makers, the Rust parity check, the IDEAS index, the
  mock round.

Every experiment that backtests takes `--engine rust` (and `--allow-stale`), with the same output. On a format with an `ENGINE`, its backtests run under those rules (`arena.cli.under_rules`: the fees, queue, mark and caps), while the matching, resting and delay each experiment varies as its modes stay its own; `premise` starts from the format's settings outright and prints them.
