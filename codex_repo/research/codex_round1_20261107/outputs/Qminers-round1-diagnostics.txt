Its sampled maximum drawdown was 1,045, versus 1,003 for the pasted strategy. F4 traded 2,387,642 lots versus 1,639,822 for the pasted strategy. The 80-lot F2 configuration earned +247,424 with peak inventory 80 and sampled drawdown 604; its quote size and skew also differ, so this is not a pure cap-only comparison.

VERIFICATION
The exported file reproduced +399,096 in 63.2 seconds wall time and 62.7 seconds CPU, using 55.6 MiB peak Windows working set. This benchmark used the official loader/engine without research callback instrumentation; other stress jobs ran concurrently. The 13,499-byte export passed the local team source validator. It has one strategy class and imports only __future__ and simulator modules. The original simulator files were unchanged. Remote Linux sandbox execution and a website score have not been measured.

METHOD
Twelve predeclared trading candidates, one no-trade control, and three old-clock controls were replayed on all 4,411,336 events. Each run started at the beginning with an intact order book; no shuffling or reset within time segments. The top two then received four higher-delay checks, followed by verification of the exact export (21 total replays including that benchmark). Official settings: depth 20 ticks, 5 ms acceptance delay, soft inventory limit 100, hard potential-exposure limit 1,000, and penalty 10,000 per second beyond the soft limit. Ranking uses final official PnL after penalties and executable terminal inventory valuation. Segment results are diagnostics on this same round, not separate independent holdouts. The winner finished flat.

Comparison phase: 16 independent worker processes on an Intel i7-12700H with 20 logical processors; observed aggregate CPU utilization reached 100%. An RTX 3070 Ti Laptop GPU with 8 GB was detected. The event-driven Python engine and frozen policies have no GPU execution path, so no GPU acceleration or additional model training was used.

¹ Drawdown is calculated from the official one-second PnL curve and can miss faster excursions. Market statistics are sampled no faster than every 100 ms and are sample-weighted.
